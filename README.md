# 🌤 Weather App

A sleek, animated weather app built with **vanilla HTML, CSS, and JavaScript** — no frameworks, no API key required.

---

## ✨ Features

- 🔍 Search weather for any city worldwide
- 🌡️ Current temperature + feels like
- 💧 Humidity, wind speed & direction, cloud cover
- 🎨 Live canvas animations (rain, snow, sun, storm, fog, clouds)
- 🌙 Day / Night mode auto-detected from the city's local time
- ⚡ Lightning bolts during thunderstorms
- 🕐 Local time shown in the city's timezone
- 📡 Powered by [Open-Meteo](https://open-meteo.com/) — free & no key needed

---

## 🛠 Tech Stack

| Layer      | Tech                          |
|------------|-------------------------------|
| Structure  | HTML5                         |
| Styling    | CSS3 (Glassmorphism)          |
| Logic      | Vanilla JavaScript (ES2022+)  |
| Canvas     | HTML5 Canvas API              |
| Weather    | [Open-Meteo API](https://open-meteo.com/) |
| Fonts      | Google Fonts — Inter          |

## 🚀 Getting Started

No setup, no install — just open it:

```bash
# Clone the repo
git clone https://github.com/your-username/weather-app.git

# Open in browser
open index.html
```

Or simply double-click `index.html`. That's it!
