# 🌤 Weather App

A simple and clean weather app built with vanilla HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Shows temperature, humidity, wind speed, and feels like
- Weather emoji based on condition
- No API key required

## Tech Stack
- HTML
- CSS (Glassmorphism design)
- JavaScript (Vanilla)
- [Open-Meteo API](https://open-meteo.com/) — free, no key needed

## How to Run
Just open `index.html` in your browser. No setup needed!
